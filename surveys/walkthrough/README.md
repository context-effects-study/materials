# The screens of the five surveys

`SURVEY_WALKTHROUGH.pdf` shows every distinct screen of the five confirmatory surveys as a participant sees it, with
one section for each survey and a caption for each screen, and `png/` holds the 32
screenshots. We made each screenshot on October 18, 2026, in a web browser, from the survey files in `../out/`, with
the pages filled from a real participant script. The question text and the code of each page are exactly as in the
survey files, the pictures come from `../png/`, and the layout is that of Qualtrics. `../README.md` describes the
placeholders for the consent text and the completion code. The confirmatory surveys ask no comprehension questions,
and the attention check is their only check question.
